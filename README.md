# Amazon Prime TV Shows Analysis

## Project Overview

This project analyzes an Amazon Prime TV Shows dataset to uncover insights into content distribution, genres, languages, IMDb ratings, and release trends. The analysis was performed using Excel, PostgreSQL, Python, and Power BI to demonstrate an end-to-end data analytics workflow.



## Objectives

- Clean and prepare the dataset.
- Analyze TV show distribution across genres and languages.
- Identify the highest-rated shows.
- Study content release trends over the years.
- Build an interactive Power BI dashboard for visualization.



## Tools & Technologies

- Microsoft Excel
- PostgreSQL
- SQL
- Python
- Pandas
- Matplotlib
- Power BI
- GitHub



## Project Workflow

1. Data Cleaning using Excel
2. Data Import and SQL Analysis using PostgreSQL
3. Exploratory Data Analysis (EDA) using Python
4. Data Visualization using Matplotlib
5. Interactive Dashboard Creation using Power BI



## SQL Analysis

The following analyses were performed:

- Total number of TV shows
- Top genres
- Top languages
- Average IMDb rating
- Highest-rated TV shows
- Shows released by year
- Distinct genres and languages



## Python Analysis

Using Pandas and Matplotlib:

- Loaded and explored the dataset
- Checked missing values
- Performed genre and language analysis
- Identified top-rated shows
- Created charts for:
  - Top Genres
  - Top Languages
  - Release Year Trend
  - IMDb Rating Distribution



## Power BI Dashboard

The dashboard includes:

- Total Shows
- Average IMDb Rating
- Highest IMDb Rating
- Top Genres
- Top Languages
- Shows Released Over Years
- Interactive filters for Genre, Language, and Release Year

## Key Insights

- Drama is one of the most common genres.
- English is the most frequently available language.
- Most TV shows have IMDb ratings between 6 and 8.
- Content releases increased significantly in recent years.
- The interactive dashboard enables easy filtering by genre, language, and release year.
